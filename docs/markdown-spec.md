# Markdown 規約 v1

```markdown
---
title: 資料タイトル          # 表紙
subtitle: 副題              # 表紙 2行目（任意）
author: 開発本部            # 表紙（任意）
date: 2026-09-02            # 表紙（任意）
agenda: once                # once | per-section | none（既定 once）
numbering: chapter          # chapter (1, 1.1) | flat (1, 2, 3) | none（既定 chapter）
layout: text                # 本文の既定レイアウト（任意）
fontSize: 18                # 本文の既定フォントサイズ（pt）。省略時はマスターの bodyStyle、無ければ 18
imageMaxPx: 2000            # 貼り付け画像の長辺上限（px）。0 で無効
maxLines: 12                # 旧互換。指定すると行数固定で判定する
---

# 章タイトル                 → 中表紙。アジェンダの項目にもなる
## 本文タイトル {layout=img-right}   → 本文スライド。属性は Pandoc 形式
- 箇条書き（2スペース字下げで階層）
- **太字** と `コード` のみインライン対応

![キャプション](images/fig.png)   → 画像。layout 未指定で画像があれば img-right

---                          → 本文内の明示的なページ分割。タイトルに (1/2) が付く
```

- 章番号・本文番号はツールが導出する。Markdown に書かない。
- `![TODO 説明]()` は画像プレースホルダ。プレビューに「未挿入」枠が出る。その行にカーソルを置いて画像を貼り付けると置き換わる。
- `> note: 本文` はスピーカーノート。本文には出ず、pptx のノートに入る。
- Markdown の表（`| a | b |` と `|---|---|`）はパワポのネイティブ表になる。本文と併記した場合は本文の下に置く。
- 画像貼り付け時のファイル名は直上の見出しから付く（`images/2-1-計測基盤の構成.png`）。
- 貼り付け・ドロップした画像は保存前に整える：長辺を `imageMaxPx`（既定 2000px）に縮小、写真のように色数が多いものは JPEG（品質 0.85）、UI キャプチャや透明のあるものは PNG のまま、GIF はそのまま。縮小が不要で再エンコードしても小さくならない場合は原本のバイト列を保つ。変更があった時だけ通知に出る。

## エディタ操作

| 操作 | 内容 |
|---|---|
| 画像を貼り付け / ドロップ | `images/` に保存し、カーソル位置に参照を挿入 |
| Ctrl-Space（`:` に続けて入力可） | スニペット `:body :section :2col :img :imgfull :table :note :split` |
| `]]` / `[[`（Normal） | 次 / 前のスライド見出しへ |
| Ctrl-S / `:w` | deck.md を保存（1.5 秒後に自動保存もされる） |
| ⌘⇧C / サムネイル右クリック | 表示中スライドの参照 `deck.md:行` をコピー。プレビュー下の参照チップは画像パスも。端末が開いていれば「端末へ」で直接貼れる |
- 章より前に置いた `##` は 1, 2, 3 と通し番号になる。
- `2col` は最初の空行で左右に分ける。
- frontmatter と最初の見出しの間の行はメモ扱いで出力されない。
- コードフェンス内の `#` は見出しとして扱わない。

## 本文量とフォントサイズ

- スライド単位のフォントサイズは見出し属性 `{size=16}`。プレビュー下の「文字 − / +」で 2pt 刻みに変えられる（属性が書き換わる）。優先順位は `size=` > frontmatter `fontSize` > マスターの bodyStyle > 18pt。
- 本文量は「表示行」で推定する（`src/model/fit.ts`）。容量 = 本文枠の高さ ÷（フォントサイズ × 1.2）。使用量は各行の折り返し後の行数の合計で、全角 1em・半角 0.55em・箇条書きの階層ごとに 1.5em の字下げ、空行 0.5 行、表は行数、画像行は 0。
- 本文枠はレイアウトごとに違う（画像 3/4 なら本文は残り幅）。画像の縦横比が分かるとさらに正確になる。
- エディタでは各本文見出しの直下にゲージ行（`本文 7 / 12 行 · 18pt`）が出る。90% で橙、超過で赤と「→ N 枚に分割」。自動分割される位置には「自動分割 2/N」の破線が入る。
- pptx 出力でも同じ推定で警告を出し、`size=` は本文の全ランに明示サイズとして書く。
- あくまで目安。PowerPoint の折り返しとは 1 行程度ずれることがある。マスターの本文枠に自動縮小（normAutofit）が付いていれば「マスターは自動縮小あり」と表示するが、方針は縮小ではなく分割。

## エディタのガイド

- 各見出しの直前に点線。章（`#`）は太い点線、本文（`##`）は細い点線、選択中のスライドはアクセント色。
- プレビューはキー入力ごとに即時再描画、保存は 1.5 秒後。

## 画像レイアウト

見出し属性で指定する。`layout=` とは独立で、`img=` があれば画像スライドになる。

```
## 構成図 {img=3/4 side=left}
```

| 属性 | 値 | 既定 |
|---|---|---|
| img | `1/1` `3/4` `1/2`（コンテンツ幅に対する画像枠の幅） | 画像がある見出しは `1/2` |
| side | `left` `right` | `right` |

配置規則（`src/layouts/geometry.ts`、単位はスライド幅）：
- 外周マージン 5%、画像と本文の間隔 3%、タイトル下 2%
- 画像はアスペクト比を保って枠に内接させ、上端と指定側に寄せる。引き伸ばさない
- `3/4` `1/2`：残り幅が本文。高さはタイトル下からスライド下端マージンまで
- `1/1`：画像の下に余りがあれば本文、なければ本文は出さず警告
- マスターから使うのはタイトル位置と `Body-Text` の書式のみ。画像枠と本文枠はツールが計算する

旧記法 `layout=img-left|img-right|img-full|img-top` は読み取り互換（それぞれ 1/2左、1/2右、1/1、1/1）。

## レイアウト id とマスター側レイアウト名

| 種別 | マスターのレイアウト名 | プレースホルダ |
|---|---|---|
| text | Body-Text | title, body |
| image (`img=`) | Body-Text | title, body（本文枠はツールが位置変更） |
| 2col | Body-2col | title, body, body |

Cover: title(ctrTitle), subTitle。Agenda: title, body。Section: title, body（任意）。

## コンソール（端末）

中央ペイン下はこのフォルダで開いた本物の端末。バーで選んだ CLI ツール（Claude Code / Codex CLI / Gemini CLI / Aider / GitHub Copilot CLI / Cursor Agent / OpenCode がプリセット、PATH 前提）がシェル起動時に自動で立ち上がる（「自動起動」で切替、「起動」で手動）。「設定」で名前・コマンド・引数を編集し、独自ツールを追加できる。設定はすべて `~/.config/mdslide/settings.json`（`MDSLIDE_CONFIG` で変更可）。「設定」シートから開ける。手で編集した内容はウィンドウにフォーカスが戻った時に反映される。

- ⌘J で表示切替、境界のドラッグで高さ変更
- Claude Code のスラッシュコマンド、許可ダイアログ、`/resume` などがそのまま使える
- フォルダに `CLAUDE.md`（deck.md の規約）が自動で置かれる。手で編集してよい
- 「終了」でシェルを終了、「再起動」で新しいシェル

## メモから資料へ（下書き）

1. 「下書き」（⌘I）に口語で書く。`notes/日付-時刻.md` に自動保存。ファイルはウィンドウのどこにドロップしても `notes/` に入る
2. コンソールでツールを起動し、「整形して deck.md に」。渡す材料はチェックで選べる（未選択なら全部）
3. 「図を統一テーマで生成」で `![TODO ...]()` が `theme.json` の配色の PNG になる。`tools/mdslide_draw.py` のフロー・ベン図・柱・サイクル・マトリクス・年表が使われる
4. 「前の版に戻す」で AI に渡す直前の `deck.md` に戻る（`.mdslide/history/`）

フォルダに自動生成されるもの：`CLAUDE.md`（規約、初回のみ）、`theme.json`（マスターから、同期）、`tools/mdslide_draw.py`（同期）、`notes/`。
