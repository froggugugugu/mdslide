# ADR-0006 画像スライドの配置はツールが計算し、マスターの画像レイアウトに依存しない

## 状況
マスター側に画像用レイアウトを複数用意すると、会社ごとに整備が必要になり、幅 1/1・3/4・1/2 × 左右の組み合わせをすべて持たせるのは現実的でない。画像のアスペクト比保持と余白は毎回手で直していた。

## 決定
- 画像スライドは `Body-Text` レイアウトを母体にし、画像は自由図形として、本文はプレースホルダの位置変更で配置する。
- 幾何は `src/layouts/geometry.ts` に一元化（マージン 5%、間隔 3%、内接フィット、上端・指定側寄せ）。
- deck.json v2 に EMU の `geometry` を含め、Python は実画像サイズで内接を再計算する。
- 指定は見出し属性 `img=1/1|3/4|1/2` と `side=left|right`。

## 結果
- マスターは 5 レイアウトだけ用意すればよい。
- 画像の引き伸ばしが起きない。プレビューと pptx が同じ計算なので見た目が一致する。
- マスターのデザイナーが画像位置を細かく決めたい場合には向かない。その場合は将来 `master-layout=` 属性で明示指定する余地を残す。
