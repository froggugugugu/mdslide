# マスター pptx の作り方

mdslide は書式（フォント・配色・背景・ロゴ・フッター）をすべて pptx のスライドマスターから取ります。どのレイアウトを何に使うかは**レイアウトの名前**で決まり、枠の位置、ロゴや帯、フォント、行間はマスターから読み取ります。次の 5 つの名前を揃えれば、手持ちのテンプレートがそのまま使えます。

| レイアウト名 | 役割 | 置くプレースホルダー | 必須 |
| --- | --- | --- | --- |
| `Cover` | 表紙 | タイトル（ctrTitle か title）、サブタイトル（subTitle か body） | 必須 |
| `Agenda` | 目次 | タイトル、本文（body か obj）1 つ | 必須 |
| `Section` | 章の中表紙 | タイトル（本文は任意） | 必須 |
| `Body-Text` | 本文 | タイトル、本文（body か obj）1 つ。本文枠はできるだけ広く | 必須 |
| `Body-2col` | 2 段組み | タイトル、本文（body か obj）2 つを左右に | 任意（無ければ 2 段を Body-Text の本文枠にまとめて入れる） |

- 名前は大文字小文字と空白を区別せず、先頭が合えば通ります。`Title Slide` / `表紙` は Cover、`TOC` / `目次` は Agenda、`Chapter` / `中表紙` / `章` と Office 既定の `Section Header` は Section として扱われます。同じ役割に当たるレイアウトが複数あると、先にあるほうが使われます。役割に当たらない名前のレイアウトは無視されます。
- 本文の枠は、役割ごとに上の数だけ置くのが確実です。説明用の枠や小見出しの枠が残っている場合、mdslide はプレビューでも書き出しでも面積の大きい枠に本文を入れます（2 段組みは大きい 2 つを左から）。
- 画像スライド用のレイアウトは要りません。画像は `Body-Text` の上にツールが配置します（ADR-0006）。
- 日付・フッター・スライド番号のプレースホルダーを各レイアウトに置くと、書き出しでスライドに複製され、番号と frontmatter の `date` が入ります。`date` が無ければ日付は出ません。マスターにだけあってレイアウトに無いものは出ません。
- 取り込むと、設定（⌘,）のマスターに「不足」「未使用」が表示されます。「不足」が空なら使えます。「不足」のまま、その役割のスライドがある資料を書き出すと「レイアウトが見つかりません」で止まります。
- 本文枠は、ヘッダやフッタ、ロゴと重ならない位置に置きます。本文の行数はマスターの行間・段落前後の間隔・内側余白から見積もり、自動分割はフッタの手前までで数えます。画像スライドの画像と本文は、ヘッダの下からフッタの手前までに置きます。ヘッダとフッタは、Body-Text レイアウトとマスターの図形・画像・日付・フッター・番号から判定します。本文・2 段組み・目次・章の本文枠がフッタやヘッダと重なると、設定のマスターに、重なっているレイアウトの名前つきで警告が出ます。本文と 2 段組みのフッタとの重なりは自動分割で避けますが、ヘッダとの重なりと、目次・章の重なりは補正しないので、PowerPoint で枠を動かします。
- マスターに置いたロゴ・背景・帯などの図形・固定文字・フッター類は、プレビューにも書き出しにも出ます。テーマのフォントと文字色もプレビューに反映されます。プレビューでは、グラデーションは先頭の色で近似し、影などの効果、パターン塗り・画像塗りの図形、表・グラフ・SmartArt、EMF / WMF / TIFF の画像は省きます。書き出した pptx ではマスターのとおりに出ます。

## まずは見本で試す

[examples/sample-master.pptx](../examples/sample-master.pptx) は、python-pptx に同梱された Office の既定テンプレート（MIT License。表示は [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)）から作った 16:9 の見本です。上の 5 つのレイアウトに必要な枠だけを置いています（ほかに、未使用の例として Blank が 1 つ）。`scripts/make_sample_master.py` で作り直せます。使い方ページからもダウンロードできます。

枠は PowerPoint の既定値ではなく、一つのグリッドから決めています（ADR-0031）。すべてのレイアウトが同じ左余白に揃い、タイトルは 2 行ぶんの帯に下端そろえで載るので、1 行でも 2 行でも文字の位置が動きません。本文はフッタの手前まで伸び、2 段組みの溝は 2 列と読める幅を取り、表紙と章の文字は黄金分割の線に置いています。文字は表紙 40pt・章 36pt・タイトル 32pt・本文 18pt（mdslide が既定で見積もる大きさ）と段を作っていて、フォントは Helvetica Neue と Hiragino Sans です。

見本は用途別に 2 つあります（ADR-0032）。設定（⌘,）のマスターで「見本（発表用）を取り込む」「見本（報告用）を取り込む」から、それぞれ保管フォルダに入ります。

| 見本 | 本文 | 向き | 版面 |
| --- | --- | --- | --- |
| `sample-master.pptx` | 18pt | 発表用。離れて読む | 余白 6%、タイトル 32pt、2 段組みの溝 4% |
| `report-master.pptx` | 11pt | 報告用。手元で読む | 余白 5%、タイトル 20pt（結論の 1 文が 2 行入る）、タイトルと本文の間隔 1.2%、色はベース・メイン・アクセントの 3 色 |

報告用は「タイトル＝結論の 1 文」「要点は最上部」「関連するものは近づける」「左端を揃える」「装飾を足さず余白と文字の大小で階層を作る」「ページ番号を必ず入れる」という前提で組んであります。図は専用レイアウトを持たず、`Body-Text` の上にツールが配置するので、`![説明](images/xxx.png)` をそのまま書けます。同じ Markdown のまま frontmatter の `master:` を書き換えれば、発表用と報告用を行き来できます。

- いちばん簡単なのはアプリ内。設定（⌘,）のマスターで「見本を取り込む」を押すと、アプリに同梱された見本が保管フォルダに入り、既定のマスターがまだ無ければ既定になる。「Finder で表示」から PowerPoint で開いて配色やロゴを直し、上書き保存すれば、そのまま自分のマスターになる（すでに同名のファイルがあるときは上書きしない。古い見本を取り込み直すときは、先に保管フォルダから消す）
- ダウンロードした場合は、資料フォルダに `master.pptx` という名前で置く（frontmatter に `master:` が無い資料はこれを使う）か、設定のマスターで「pptx を取り込む」

## 見本はどこに置かれるか

- 設定（⌘,）のマスターで「見本を取り込む」を押すと、マスターの保管フォルダに `sample-master.pptx` として書かれる。保管フォルダは既定で `~/.config/mdslide/masters/`（設定 `masters.dir` で変更可）。同じ画面の「Finder で表示」で開ける
- 手元で開きたいだけなら、リポジトリの `examples/sample-master.pptx` か、使い方サイトからのダウンロードでも同じもの

## 実運用のスライドから作る（見本を横に置いて）

いま使っているスライドを土台にすると、フォント・配色・ロゴ・フッターがそのまま残る。見本は「レイアウト名とプレースホルダーの手本」として横に開いておく。

1. 実運用の pptx を複製し、複製のほうを PowerPoint で開く。「表示」→「スライドマスター」
2. 見本 `sample-master.pptx` をもう一つのウィンドウで同じくスライドマスター表示にし、レイアウト一覧の名前と、各レイアウトにあるプレースホルダー（タイトル、本文、サブタイトル）を見比べる
3. 実運用側で、表紙に使っているレイアウトを右クリック →「レイアウト名の変更」→ `Cover`。同じ要領で目次を `Agenda`、章の中表紙を `Section`、本文を `Body-Text`、2 段組みを `Body-2col` にする。名前は見本からコピーすると間違えない
4. 対応するレイアウトが無い役割は、近いレイアウトを右クリック →「レイアウトの複製」で作り、「プレースホルダーの挿入」→「コンテンツ」で本文枠を置く。見本の同じ名前のレイアウトと枠の構成が同じになっていればよい
5. 「マスター表示を閉じる」。通常のスライドを全部削除し、`master.pptx`（または会社名などの分かる名前）で保存する
6. 設定のマスターで「pptx を取り込む」。カードに 5 つの役割のレイアウト名（並びはマスター内の順）が並び、「不足」が出なければ完成。ツールバーのマスター選択で保管フォルダのマスターを選ぶと、frontmatter に `master: 名前.pptx` と書かれる（「このフォルダの master.pptx」を選んだときは書かれない）

AI に任せる場合は、後述の「AI に頼む（プロンプト）」の 1 行目を実運用の pptx のファイル名にして貼り付ける。

## 装飾入りの見本（テスト用）

`examples/decorated-master.pptx` は、見本に企業マスターらしい装飾を足したものです。表紙は全面の生成画像（夜景）と写真風のタイル 3 枚とロゴ、章は左の画像帯。表紙以外のレイアウトにはヘッダ帯（ドット模様とロゴ）とフッタ帯（アイコン、固定文字、日付、ページ番号）が出ます。フォントは Avenir Next / Hiragino Sans、配色は紺・青緑・橙。プレビューと書き出しにマスターの要素がどう出るかを試すときに使います。画像はすべて Pillow で描いたもので、`scripts/make_decorated_master.py` で作り直せます（見本 `examples/sample-master.pptx` に装飾を足します）。

## 手持ちのパワポから作る（PowerPoint での手順）

1. 普段使っているテンプレートを開き、「表示」→「スライドマスター」。左の一覧に並ぶのがレイアウトです。
2. 表紙に使っているレイアウトを右クリック →「レイアウト名の変更」で `Cover` にします。同じ要領で、目次を `Agenda`、章の中表紙を `Section`、本文を `Body-Text`、2 段組みを `Body-2col` に。
3. 該当するレイアウトが無い役割は、近いものを右クリック →「レイアウトの複製」で作り、「プレースホルダーの挿入」→「コンテンツ」で本文枠を置きます。Agenda は Body-Text の複製で十分です。
4. 「マスター表示を閉じる」。通常のスライド（ページ）は全部削除し、`master.pptx` として保存します。
5. 資料フォルダに置くか、設定のマスターで取り込みます。「不足」が出なければ完成です。

## テンプレートから変換する（スクリプト）

いちばん簡単なのはアプリからです。設定（⌘,）のマスターで「テンプレートから変換」を押し、手持ちの pptx を選ぶと、変換したマスターが保管フォルダに入ります（書き出しと同じ Python を使います。同じ名前のファイルがあるときは上書きしません）。

端末から実行するときは `tools/convert_master.py` を直接呼びます。

```
python3 tools/convert_master.py 手持ちのテンプレート.pptx -o master.pptx --profile report
```

`--profile` は、本文ページの余白と文字の大きさをどちらの見本に合わせるかです（`report` = 本文 11pt、`presentation` = 本文 18pt。既定は `report`）。アプリからはボタンの隣の選択で切り替えます。

- 元のファイルを土台にします。テーマ・フォント・配色・ロゴ・ヘッダ・フッタには触りません（パッケージをまたいだコピーをしないので、書式が欠けたり崩れたりしません）。
- 変えるのは mdslide が読む所だけです。役割の近いレイアウトを選んで `Cover / Agenda / Section / Body-Text / Body-2col` に改名し（足りない役割は本文レイアウトを複製）、役割として読まれてしまう残りの名前には `Unused-` を付け、本文の枠をスライドの幅いっぱい・タイトルの下からヘッダとフッタの手前までに置き直し、本文に使わない枠（説明用・小見出し・画像）を外し、元のページを削除します。日付・フッター・スライド番号の枠は残します。
- 本文枠を元のテンプレートから引き継がないのは、狭い枠のままだと mdslide が「1 ページに 1 行」と見積もって分割してしまうためです（ADR-0030）。表紙だけは意匠が強く出るので、枠を動かさず、サブタイトルが無いときだけ足します。
- 最後にレイアウト名・枠の大きさ・本文の行数の目安が一覧で出ます。「本文およそ N 行」が小さすぎるときは、マスターのヘッダ・フッタの帯が厚すぎます。
- 配布アプリを使っているときは、同梱の `/Applications/mdslide.app/Contents/Resources/tools/convert_master.py` を同じように実行します。python-pptx が入った Python は、設定の「書き出し」が示すもの（既定は `~/.config/mdslide/venv/bin/python3`）です。
- 変換したら、設定（⌘,）のマスターで取り込み、「不足」が出ないことを確かめます。
- 変換しても表紙や中表紙のタイトルが空のままなら、見た目はタイトルでも中身が本文の枠になっているテンプレートです。設定のマスターにある「AI に渡すプロンプト」をコピーして、コンソールの Claude Code などに貼ってください。意匠を保ったまま、その枠をタイトルへ昇格させてもらえます。

## AI に頼む（プロンプト）

Claude Code や ChatGPT にテンプレートの pptx を渡し、次をそのまま貼り付けます。1 行目のファイル名だけ書き換えてください。

```text
手元の PowerPoint テンプレート（ファイル名: ここに書く.pptx）を、mdslide 用のスライドマスター master.pptx に変換してください。

進め方
- mdslide の変換スクリプトを使ってください。これが正しい変換方法です。リポジトリなら tools/convert_master.py、配布アプリなら /Applications/mdslide.app/Contents/Resources/tools/convert_master.py です。
  python3 tools/convert_master.py ここに書く.pptx -o master.pptx
- 実行したら、最後に出る一覧（レイアウト名・枠の大きさ・本文の行数の目安）をそのまま貼ってください。

スクリプトが使えない環境のときだけ、次の条件を満たす master.pptx を自分で作ってください
- レイアウト名を Cover / Agenda / Section / Body-Text / Body-2col に揃える（大文字小文字と空白は無視されます）。足りない役割は本文のレイアウトを複製して作る。ほかのレイアウトの名前が Title Slide、Section、Chapter、TOC、表紙、目次、中表紙、章 で始まるときは、先にあるほうが使われるので名前を変える
- 置く枠は、Cover がタイトルとサブタイトル、Agenda と Body-Text がタイトルと本文 1 つ、Section がタイトルのみ、Body-2col がタイトルと本文 2 つ（左右）。日付・フッター・スライド番号の枠は残し、それ以外の枠（説明用・小見出し・画像）は削除する
- 本文の枠は、元のテンプレートの大きさを引き継がず、置き直す。左右はスライド幅の 5% を余白にし、上はタイトルの下端からスライド幅の 2% 下、マスターのヘッダとフッタからはスライド幅の 1% 離す。2 段組みはスライド幅の 3% を空けて左右に等分する。狭い枠のままだと、mdslide は 1 ページに 1 行しか入らないと見積もって分割する
- 元のテーマ・フォント・配色・ロゴ・ヘッダ・フッタは変えない。新しいテーマは作らない
- 通常のスライド（ページ）はすべて削除する
- python-pptx で XML を触るときは、要素名を必ず pptx.oxml.ns.qn() で解決する（名前空間を手で書くと、読み込めても PowerPoint が開けないファイルになる）
- 最後に、各レイアウトの名前と枠（種類・idx・位置）を一覧で出力する
```

## 確認

- 設定（⌘,）のマスターで、そのマスターのカードに 5 つの役割のレイアウト名が並び、「不足」が出ていないこと。
- サンプル資料を開いてプレビューが崩れていないこと。本文枠が狭いと「本文 N / M 行」のゲージがすぐ赤くなるので、その場合は `Body-Text` の本文プレースホルダーを広げます。
- 書き出した `out/deck.pptx` を開き、フォントと配色が元のテンプレートどおりであること。
