# マスター pptx の作り方

mdslide は書式（フォント・配色・背景・ロゴ・フッター）をすべて pptx のスライドマスターから取ります。ツールが見るのは**レイアウトの名前**だけです。次の 5 つの名前を揃えれば、手持ちのテンプレートがそのまま使えます。

| レイアウト名 | 役割 | 置くプレースホルダー | 必須 |
| --- | --- | --- | --- |
| `Cover` | 表紙 | タイトル（ctrTitle か title）、サブタイトル（subTitle か body） | 必須 |
| `Agenda` | 目次 | タイトル、本文（body か obj）1 つ | 必須 |
| `Section` | 章の中表紙 | タイトル（本文は任意） | 必須 |
| `Body-Text` | 本文 | タイトル、本文（body か obj）1 つ。本文枠はできるだけ広く | 必須 |
| `Body-2col` | 2 段組み | タイトル、本文（body か obj）2 つを左右に | 任意（無ければ Body-Text で代用） |

- 名前の大文字小文字と空白は区別しません。`Title Slide` / `表紙` は Cover、`TOC` / `目次` は Agenda、`Chapter` / `中表紙` / `章` は Section としても通ります。
- 画像スライド用のレイアウトは要りません。画像は `Body-Text` の上にツールが配置します（ADR-0006）。
- 日付・フッター・スライド番号のプレースホルダーはあってもかまいません。5 つ以外のレイアウトが残っていても無視されます。
- 取り込むと、設定（⌘,）のマスターに「不足」「未使用」が表示されます。「不足」が空なら使えます。
- 本文枠は、ヘッダやフッタ、ロゴと重ならない位置に置きます。本文の行数はマスターの行間・段落前後の間隔・内側余白から見積もり、自動分割と画像スライドの本文はフッタの手前までに収めます。本文枠がフッタと重なっていると、設定のマスターに警告が出ます。
- マスターに置いたロゴ・背景・帯などの図形・固定文字・フッター類は、プレビューにも書き出しにも出ます。テーマのフォントと文字色もプレビューに反映されます（グラデーションや効果、SmartArt は近似か省略）。

## まずは見本で試す

[examples/sample-master.pptx](../examples/sample-master.pptx) は、Office 標準テーマのレイアウトを規約どおりに名前を変えただけの 16:9 の見本です。使い方ページからもダウンロードできます。

- いちばん簡単なのはアプリ内。設定（⌘,）のマスターで「見本を取り込む」を押すと、アプリに同梱された見本が保管フォルダに入り、最初の 1 つなら既定になる。「Finder で表示」から PowerPoint で開いて配色やロゴを直し、上書き保存すれば、そのまま自分のマスターになる（すでに同名のファイルがあるときは上書きしない）
- ダウンロードした場合は、資料フォルダに `master.pptx` という名前で置く（frontmatter に `master:` が無い資料はこれを使う）か、設定のマスターで「pptx を取り込む」

## 見本はどこに置かれるか

- 設定（⌘,）のマスターで「見本を取り込む」を押すと、マスターの保管フォルダに `sample-master.pptx` として書かれる。保管フォルダは既定で `~/.config/mdslide/masters/`（設定 `masters.dir` で変更可）。同じ画面の「Finder で表示」で開ける
- 手元で開きたいだけなら、リポジトリの `examples/sample-master.pptx` か、使い方サイトからのダウンロードでも同じもの

## 実運用のスライドから作る（見本を横に置いて）

いま使っているスライドを土台にすると、フォント・配色・ロゴ・フッターがそのまま残る。見本は「レイアウト名とプレースホルダーの手本」として横に開いておく。

1. 実運用の pptx を複製し、複製のほうを PowerPoint で開く。「表示」→「スライドマスター」
2. 見本 `sample-master.pptx` をもう一つのウィンドウで同じくスライドマスター表示にし、レイアウト一覧の名前と、各レイアウトにあるプレースホルダー（タイトル、本文、サブタイトル）を見比べる
3. 実運用側で、表紙に使っているレイアウトを右クリック →「レイアウト名の変更」→ `Cover`。同じ要領で目次を `Agenda`、章の中表紙を `Section`、本文を `Body-Text`、2 段組みを `Body-2col` にする。名前は見本からコピーすると間違えない
4. 対応するレイアウトが無い役割は、近いレイアウトを右クリック →「レイアウトの複製」で作り、「プレースホルダーの挿入」→「コンテンツ」で本文枠を置く。見本の同じ名前のレイアウトと枠の構成が同じになっていればよい
5. 「マスター表示を閉じる」。通常のスライドを全部削除し、`master.pptx`（または会社名などの分かる名前）で保存する
6. 設定のマスターで「pptx を取り込む」。カードに `Cover · Agenda · Section · Body-Text · Body-2col` が並び「不足」が出なければ完成。ツールバーのマスター選択で資料に割り当てると frontmatter に `master:` として書かれる

AI に任せる場合は、次節のプロンプトの 1 行目を実運用の pptx のファイル名にして貼り付ける。

## 装飾入りの見本（テスト用）

`examples/decorated-master.pptx` は、見本に企業マスターらしい装飾を足したものです。表紙は全面の生成画像（夜景）と写真風のタイル 3 枚とロゴ、章は左の画像帯、本文はヘッダ帯（ドット模様とロゴ）とフッタ帯（アイコン、固定文字、日付、ページ番号）。フォントは Avenir Next / Hiragino Sans、配色は紺・青緑・橙。プレビューと書き出しにマスターの要素がどう出るかを試すときに使います。画像はすべて Pillow で描いたもので、`scripts/make_decorated_master.py` で作り直せます。

## 手持ちのパワポから作る（PowerPoint での手順）

1. 普段使っているテンプレートを開き、「表示」→「スライドマスター」。左の一覧に並ぶのがレイアウトです。
2. 表紙に使っているレイアウトを右クリック →「レイアウト名の変更」で `Cover` にします。同じ要領で、目次を `Agenda`、章の中表紙を `Section`、本文を `Body-Text`、2 段組みを `Body-2col` に。
3. 該当するレイアウトが無い役割は、近いものを右クリック →「レイアウトの複製」で作り、「プレースホルダーの挿入」→「コンテンツ」で本文枠を置きます。Agenda は Body-Text の複製で十分です。
4. 「マスター表示を閉じる」。通常のスライド（ページ）は全部削除し、`master.pptx` として保存します。
5. 資料フォルダに置くか、設定のマスターで取り込みます。「不足」が出なければ完成です。

## AI に頼む（プロンプト）

Claude Code や ChatGPT にテンプレートの pptx を渡し、次をそのまま貼り付けます。1 行目のファイル名だけ書き換えてください。python-pptx が使える環境ならスクリプトで、使えなければ PowerPoint での手順を返します。

```text
手元の PowerPoint テンプレート（ファイル名: ここに書く.pptx）を、mdslide 用のスライドマスター master.pptx に変換してください。

前提
- mdslide は Markdown からスライドを生成するツールで、書式（フォント・配色・背景・ロゴ・フッター）はこの master.pptx のスライドマスターとレイアウトから取ります。元ファイルのテーマはそのまま残し、新しいテーマは作らないでください。
- レイアウトは名前で役割を判定します。名前は次の 5 つに揃えてください（大文字小文字と空白は無視されます）。

必要なレイアウトとプレースホルダー
- Cover: 表紙。タイトル（ctrTitle か title）とサブタイトル（subTitle か body）を 1 つずつ
- Agenda: 目次。タイトル 1 つと本文（body か obj）1 つ。本文には箇条書きが入ります
- Section: 章の中表紙。タイトル 1 つ（本文は無くてもよい）
- Body-Text: 本文。タイトル 1 つと本文（body か obj）1 つ。本文枠はできるだけ広く
- Body-2col: 2 段組み。タイトル 1 つと本文（body か obj）2 つを左右に
- 画像用のレイアウトは不要です（ツールが Body-Text の上に画像を配置します）。日付・フッター・スライド番号のプレースホルダーはあってもかまいません。

作業
1. 元ファイルのスライドマスターにあるレイアウトを一覧し、役割の近いもの（例: Title Slide → Cover、Title and Content → Body-Text、Two Content → Body-2col、Section Header → Section）を選んで上の名前に変更してください。
2. 該当するものが無い役割は、近いレイアウトを複製して作ってください。Agenda は Body-Text の複製でかまいません。
3. 上の 5 つ以外のレイアウトは残してもかまいません（mdslide は無視します）。
4. 通常のスライド（ページ）はすべて削除し、マスターとレイアウトだけのファイルにしてください。
5. master.pptx として保存し、最後に各レイアウトの名前とプレースホルダー（種類・idx・位置）を一覧で出力してください。

進め方
- python-pptx が使えるならスクリプトで行い、そのスクリプトも示してください。python-pptx はレイアウトの名前変更とスライドの削除はできますが、レイアウトの複製は XML 操作が必要です。難しければ、PowerPoint の「表示 > スライドマスター」で行う手順（右クリック > レイアウト名の変更、レイアウトの複製、プレースホルダーの挿入）を代わりに示してください。
```

## 確認

- 設定（⌘,）のマスターで、そのマスターのカードに `Cover · Agenda · Section · Body-Text · Body-2col` が並び、「不足」が出ていないこと。
- サンプル資料を開いてプレビューが崩れていないこと。本文枠が狭いと「本文 N / M 行」のゲージがすぐ赤くなるので、その場合は `Body-Text` の本文プレースホルダーを広げます。
- 「書き出す」で `out/deck.pptx` を開き、フォントと配色が元のテンプレートどおりであること。
